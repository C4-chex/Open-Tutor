## Top 3 Marketing Highlights This Week

### 1. Show HN: FSRS-5/6 upgrade with trainable forgetting curve decay
The Oct 13 community posts feature a technically precise Show HN submission on OpenTutor's upgrade from FSRS 4.5 (17 parameters) to FSRS-5/6 (21 parameters). The key technical differentiators: the forgetting curve decay `w[20]` is now a trainable parameter (`R(t) = (1 + factor * t / S)^(-decay)`), same-day review handling prevents stability inflation from multiple intra-day reviews (a behavior gap vs. Anki), and difficulty initialization switched to exponential (`D0 = w4 - exp(w5 * (G-1)) + 1`) for better early-card calibration. The implementation is 304 lines in `apps/api/services/spaced_repetition/fsrs.py`. **This is ready to post** — it targets Anki power users and ML practitioners who'll recognize the significance of a trainable decay parameter. The comparison to Anki (same-day review gap) is a concrete, verifiable differentiator.

### 2. r/LocalLLaMA: Circuit breaker + provider fallback with model size hints
The Oct 13 community batch includes a detailed r/LocalLLaMA post on OpenTutor's multi-provider LLM router (`apps/api/services/llm/router.py`, 399 lines). The progressive cooldown strategy (5s → 10s → 20s → 60s), circuit-open threshold (3 failures → 2-minute cooldown + auto-probe), and model-size hint system (`"fast"` vs. `"large"` mapped to different configured models) are all explained with copy-pasteable config examples. The pattern generalizes beyond OpenTutor — this is useful for anyone building multi-step agents on local hardware with mixed model sizes. **Strong match for the r/LocalLLaMA audience** (Ollama users, local LLM builders, constrained-hardware developers).

### 3. Socratic FSM — still the sharpest demonstration of pedagogical reasoning in code
The Week 40 Socratic engine post (from Oct 4) remains unposted on Twitter/X and r/LocalLLaMA based on available marketing records. The content is the strongest technical narrative in the archive: a 5-state FSM (PROBE, CLARIFY, CONFRONT, SCAFFOLD, CONFIRM) with 20 explicit transitions, behavioral-signal-based initial-state selection, a 4-turn escape hatch that overrides Socratic questioning with direct explanation.
